# Internal V1 implementation plan

Goal: a local Windows logo-on-product workstation, with recoverable logo cleanup, direct manipulation, accurate exports, and a self-contained Python runtime. Customer website is deferred.

Architecture: FastAPI + versioned JSON projects + local SVG/Pillow processing + Inkscape CLI; plain JavaScript SVG editor. The browser is a local UI, not a hosted site. Source vector artwork is never regenerated by AI.

Authority: `2026-09-04-design-review-and-v2-proposal.md` and user approval to continue.

Global constraints:
- Preserve original projects and inputs. Backup source before editing. No Git repository exists; use the source zip for recovery/review, do not create a repository or commits.
- Windows EXE includes Python runtime; Inkscape remains an external dependency. No system-level install without authority.
- Canonical geometry: size_mm and offset_mm, bottom/left relative to selected reference frame. Reproject logo_px from these when calibration/frame changes. Uncalibrated projects may be saved, not exported.
- Clean PNG contains only supplied product pixels and selected logo, never UI guides, badges or size captions. Baked-in product annotations need user crop; no invented restoration.
- Import heuristics are reversible suggestions. Preserve original source, expose objects/candidates, and never promise perfect dimension recognition.
- All exported files derive from one validated project revision and an immutable asset version. SVG is self-contained, PDF logo spec is 1:1.

## Task 1 — persistence and geometry (controller)
Files: app/models.py, config.py, routers/project.py, upload.py, services/geometry.py; tests/test_projects.py.
Test first: reject path traversal/non-finite dimensions; conflicting revisions cannot overwrite newer work; new upload invalidates derived asset; calibration edits preserve millimeters and change pixels; old orders load without being rewritten.
Implement validated compatible models, revision-checked writes, list/open/clone, immutable input versions, frozen data/resource paths.

## Task 3 — asset pipeline (controller)
Files: services/assets.py, svg_document.py, raster_assets.py, engine/inkscape.py, routers/convert.py; tests/test_assets.py.
Test first vector tight bounds/nonzero origin/group transforms; candidate separation; dimensions/background flagged but recoverable; raster corner-background transparency. Validate against copies of user 01/02, render results.
Implement safe local source normalization, object geometry queries, conservative heuristics, user-selected objects/candidates, tight normalized clean SVG + transparent preview. SVG/AI/PDF supported through Inkscape; raster stays raster. Reject dangerous embedded content/external dependencies.

## Task 4 — exports (controller)
Files: services/spec_svg.py, placement_svg.py, selection_png.py, routers/export.py; tests/test_exports.py.
Test first 1:1 SVG mapping, no guide pixels/captions in clean PNG, embedded artwork in placement, immutable revision export with proper failure reporting. Generate SVG/PDF/PNG from same selected asset and geometry; comparison optional, labels outside photo. Visually render PDF and compare.

## Task 5 — integration and packaging
Files: launcher.py, LogoMock.spec, build.bat, run.bat, requirements*.txt, README.md.
Run core test suite once after integration, inspect live UI, import user-copy assets, exercise handles/save/reopen/export. Independent review of change package. Build and smoke-launch executable. Deliver known limits honestly; no cloud work.
