## 4. 不可违反的约束（最容易搞错的四条）

1. **S1 效果图禁止用生成式 AI**（Nano Banana / Gemini / Seedream 之类）。它重画一张图，logo 尺寸位置就反推不回毫米数，下游全部断链。必须程序化 alpha 合成平铺叠加。
2. **S2 全链路每个数字必须可复现、可追溯。** 由此推出**边界框不使用 AI 视觉识别**——`px_per_mm` 从框算出，框的不确定性会直接污染所有下游毫米数。Joe 曾问是否用 AI 识别框或与 WorkBuddy / 千问联动，结论是不用（论证见设计文档 6.4）。

## 5. v0.2 核心结论速查

| 项 | 结论 |
|----|------|
| 定位模型 | **通用自由画框**，废弃语义区枚举 |
| 框的双重身份 | 安全区（logo 拖不出框）+ 尺寸基准（尺寸链相对框边） |
| 框的硬约束 | **每条边必须落在包身肉眼可辨的物理特征上**，否则包厂在实物上找不到框 |
| 标定两步 | 2A 产品框（定比例尺）+ 2B logo 框（定基准） |
| 比例尺 | **以宽度定标**（软包宽度比高度可靠），高度选填仅提示 |
| 参照物 | 不能加（图由工厂/客户给） |
| 背景分割 | 不做（包身包围盒不需要） |
| 透视告警 | 原 2% 硬告警**降级为黄色提示**，须列明三种成因 |
| 定位图标注 | 仅 logo 尺寸 + 距框边两个距离 |
| 三份同源落点 | 三条分支读同一个 `schemes[i]` 里已算好的 mm 值，彼此无换算关系 |
