# LogoMock 绿色版使用说明

## 推荐使用方式

对外分享时，推荐采用以下组合：

- `LogoMock` 绿色版：解压后直接运行，无需安装 Python。
- `Inkscape` 官方稳定版 64 位 MSI 安装版：负责 SVG / PDF / AI 的解析和 PDF 导出。

这是默认方案：LogoMock 发布包体积小，Inkscape 可按官方渠道独立更新，使用者也不容易因移动文件夹而丢失程序路径。

请只从 [Inkscape 官方下载页](https://inkscape.org/release/) 下载 Windows 64 位 **Windows Installer Package (MSI)** 并完成安装。

## 首次使用

1. 从 GitHub Release 下载 LogoMock Windows 发布压缩包，解压到自己有写入权限的文件夹，例如 `D:\LogoMock`；不要解压到 `Program Files`。
2. 双击 `run.bat`，浏览器会打开本地工作台；不需要安装 Python。
3. 安装官方 Inkscape 64 位 MSI 版。
4. 回到工作台“设置”，确认显示“Inkscape 已就绪”。如未自动识别，手动选择 `C:\Program Files\Inkscape\bin\inkscape.exe`。
5. 项目素材、自动保存和导出都保存在同目录的 `projects/`。请定期备份此目录。

## Inkscape 的作用

导入或清理 SVG、PDF、AI Logo，以及导出 PDF 时，需要 Inkscape。仅使用 PNG / JPG / WebP 并只导出 PNG 时，基础排版可用；但仍建议安装 Inkscape，以免后续素材格式受限。

AI 文件必须在 Illustrator 中以“创建 PDF 兼容文件”方式保存；LogoMock 会按 PDF 的第一页处理。

## 何时使用便携版 Inkscape

只有以下情况才建议使用便携版：

- 电脑没有安装权限。
- 需要在同一电脑测试多个 Inkscape 版本。
- 需要在离线电脑或 U 盘环境中完整携带。

便携版请同样从 Inkscape 官方发布页下载 `.7z` 包，解压到固定位置后，在 LogoMock 设置中选择其 `bin\inkscape.exe`。不要把它混入默认发布包：当前便携 Inkscape 约 552 MB，会明显增大发送、下载和后续更新成本。

## 常见问题

### 双击后打不开

确认 `LogoMock.exe` 与 `run.bat` 在同一文件夹；请从解压后的文件夹运行，不要直接在压缩包预览中双击。

### 找不到 Inkscape

在工作台“设置”里手动选择 `inkscape.exe`。如果安装版路径不同，以实际安装位置为准。

### 分享项目给同事

只分享发布包；项目文件请单独复制相应的 `projects/` 子目录。不要把 `config.json`、整个 `projects/` 或客户素材提交到 GitHub。

### 导出的 PNG 出现编辑框

正常的 `mockup-*.png` 不含编辑框、尺寸条或方案编号；若产品原图本身已有文字或尺寸标注，需要换用无标注原图或使用裁剪。
