# LogoMock 绿色版使用说明

## 推荐组合

- `LogoMock` 绿色版：解压后运行，不需要安装 Python。
- 官方稳定版 Inkscape 64 位 MSI 安装版：读取、分析 SVG / PDF / AI Logo。

这是默认组合。LogoMock 发给同事时体积小；Inkscape 由官方独立更新，也不会因为移动绿色版文件夹而失效。

请从 [Inkscape 官方下载页](https://inkscape.org/release/) 下载 Windows 64 位 **Windows Installer Package (MSI)** 并完成安装。

## 首次使用

1. 从 GitHub Release 下载 Windows 发布压缩包，解压到有写入权限的文件夹，例如 `D:\LogoMock`；不要放在 `Program Files`。
2. 双击 `run.bat`。浏览器会打开本地工作台；不需要安装 Python。
3. 安装官方 Inkscape 64 位 MSI 版。
4. 在工作台右上角打开“设置”。若未显示“Inkscape 已就绪”，手动选择 `C:\Program Files\Inkscape\bin\inkscape.exe`。
5. 所有产品图、Logo、任务草稿和版本都保存在同目录的 `projects/`。请备份该目录。

## 一张确认图的制作方式

新建任务后，依次导入产品图、导入并确认 Logo、按原有方式标定产品尺寸、调整 Logo 的位置/宽高/颜色，然后点击“生成客户确认图”。

生成时选择 PNG 保存位置。输出仅有一张客户确认图：干净产品图加 Logo，并标注数值 `宽 × 高 mm`。编辑框、参考线、版本号、颜色说明不会被画进图片。

生成成功后，软件会把这一状态自动存进“版本记录”。客户反馈后，打开相应任务，选择旧版本并点击“从此版本继续编辑”；修改、生成，再形成下一版。删除版本只删除软件内部存档，不会影响先前已经发送或保存到外部的 PNG。

## Logo 文件说明

- 产品图支持 PNG / JPG / JPEG / WebP。
- Logo 支持 SVG / PDF / PDF 兼容 AI / PNG / JPG / JPEG / WebP。
- AI 必须在 Illustrator 中启用“创建 PDF 兼容文件”保存。非 PDF 兼容 AI 无法读取。
- PDF 和 PDF 兼容 AI 会读取可解析的页面，不只读取第一页。业务员只需在“确认 Logo”中勾选所需的内容；组合好的字标会尽量作为一个整体出现。

软件会尝试排除背景、尺寸标注和无关图形，但这只是辅助分析。使用确认前请看右侧预览；若 Logo 与背景或标注连成一个整体，建议向客户索取更干净的原始文件。

## 什么时候使用便携版 Inkscape

仅在以下情况下使用便携版：电脑没有安装权限、需要同时测试多个 Inkscape 版本，或必须在离线电脑/U 盘上完整携带。

便携版也应从官方发布页下载 `.7z` 包，解压到固定位置后，在 LogoMock 的“设置”中选择它的 `bin\inkscape.exe`。不要把便携 Inkscape 混入默认发布包，体积大且更新麻烦。

## 常见问题

### 双击后打不开

确认 `LogoMock.exe` 与 `run.bat` 在同一文件夹；请从解压后的文件夹运行，不要直接在压缩包预览中双击。

### 找不到 Inkscape

在工作台“设置”中手动选择 `inkscape.exe`。安装版通常是 `C:\Program Files\Inkscape\bin\inkscape.exe`；若实际安装位置不同，以实际路径为准。

### AI 导入失败

请让客户重新导出为 PDF，或让客户在 Illustrator 中开启“创建 PDF 兼容文件”后再保存 AI。

### 已导出的图出现编辑框

客户确认图不会画入编辑框或参考线。若图片本身仍有文字、尺寸线或边框，通常来自原始产品图或勾选进来的 Logo 内容；请更换无标注产品图，或重新确认 Logo 内容。

### 交接给同事

复制绿色版发布包供其安装使用；项目数据只需单独复制对应的 `projects/<任务名称>/` 文件夹。不要将整个 `projects/`、`config.json` 或客户素材上传到 GitHub。
